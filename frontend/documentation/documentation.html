Overview

What is ShieldAI Firewall?

ShieldAI is an intelligent zero-trust privacy proxy positioned in front of external LLMs. It continuously inspects inbound prompt strings, enforces compliance policies, and removes sensitive PII/secrets before network transmission.

Architecture

Detection Mechanics

Inspection executes through a hybrid pipeline combining pre-compiled regex automata, high-entropy token analysis (for secrets & API keys), and pattern heuristics for structured personal identifiers.

Analytics

Risk Index Calculation

Each detected entity carries an assigned threat weight. A mathematical function aggregates detected categories into a standardized scale of 0 to 100, driving policy thresholds.

Governance

Policy Profiles

Strict: Masks all PII, redacts financial/health records, and hard-blocks any developer secrets.
Balanced: Masks direct identifiers while allowing general operational context.
Minimal: Enforces tripwires only on critical API tokens and credentials.

Endpoints

Core REST Endpoints

  • POST /api/scan • Primary inspection endpoint
  • GET /api/policies • Retrieve active enforcement rules
  • GET /api/scans • Retrieve recent telemetry records
  • GET /api/health • Cluster liveness and readiness probe
Compliance

Zero-Retention Security Model

Prompts are processed in-memory and sanitized ephemerally. No unencrypted prompt bodies are written to permanent databases, ensuring complete adherence to GDPR and HIPAA data handling rules.
