How It Works

Your Data Gets Protected Before AI Sees It

ShieldAI works as a security layer between you and the external AI model. It checks your prompt before anything sensitive can leave your application.

01
👤

User Prompt

The user enters a prompt containing normal text and possibly sensitive data.

"My email is ajay@gmail.com "
→
02
🔍

Detect

ShieldAI scans the prompt and identifies sensitive information such as email, phone, password and API keys.

EMAIL DETECTED
→
03
📊

Risk Score

Every detected data type receives a risk value and ShieldAI calculates the overall privacy risk.

Risk: 40/100
→
04
🛡️

Protect

Based on security policies, ShieldAI can mask, redact, tokenize or block sensitive information.

[EMAIL] PROTECTED
→
05
🤖

Safe AI

Only the sanitized prompt is sent to the external AI model for processing.

✓ SAFE PROMPT
🛡️

Core Security Rule

Raw sensitive data must never be sent directly to the external AI model.

Protected
User → ShieldAI → Detection → Protection → Safe AI
